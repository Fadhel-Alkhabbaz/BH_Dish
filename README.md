## 📖 Overview

**Luqma (لقمة)** is an AI-powered Computer Vision web application built using **Streamlit** and custom-trained **YOLO (YOLO26 Object Detection)** models. The application is designed to detect and recognize authentic Bahraini traditional dishes from images, camera inputs, and video uploads in real-time.

---

## 🍽️ Supported Bahraini Dishes

The model is trained to recognize **10 iconic Bahraini dishes**:

| Dish Name (English) | Arabic Name | Description |
| :--- | :--- | :--- |
| **Chicken Machboos** | مكبوس الدجاج | Traditional spiced rice dish served with cooked chicken. |
| **Balaleet** | بلاليط | Sweet and savory noodles topped with an omelet. |
| **Luqaimat** | لقيمات | Deep-fried crispy sweet dumplings served with date syrup. |
| **Harees** | هريس | Slow-cooked wheat and meat porridge served with melted ghee. |
| **Regag Bread** | خبز الرقاق | Extremely thin traditional Bahraini flatbread. |
| **Sambosa** | سمبوسة | Crispy stuffed triangular pastry filled with meat or veggies. |
| **Thareed** | ثريد | Thin crispy regag bread soaked in rich meat/vegetable stew. |
| **Ghoozi** | قوزي | Roasted meat served over a large bed of seasoned rice. |
| **Bahraini Halwa** | حلوى بحرينية | Traditional gelatinous sweet made with saffron, cardamom, and nuts. |
| **Tikka** | تكة | Charcoal-grilled marinated meat skewers. |
